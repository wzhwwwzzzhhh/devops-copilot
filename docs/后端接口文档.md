## 1. 聊天接口

### 1.1 SSE 流式对话（POST）

**接口**: `POST /api/chat`

**描述**: 发送用户消息，通过 SSE（Server-Sent Events）流式返回 AI 处理结果。

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|:------|:----|:----|:------|
| message | String | 是 | 用户输入的消息内容 |
| sessionId | String | 否 | 会话 ID，不传则自动生成 |

**请求示例**:
```bash
curl -X POST "http://localhost:8080/api/chat?message=order-service的create接口错误率突然到20%了，帮我看看&sessionId=test-001"
```

**响应**: `SseEmitter`（流式响应）

**SSE 事件类型**:
- `message`: 处理过程中的输出内容
- `done`: 处理完成标识
- `error`: 错误信息

---

### 1.2 SSE 流式对话（GET）

**接口**: `GET /api/chat`

**描述**: 与 POST 方法相同，支持 GET 方式调用。

**请求参数**: 同 POST 方法

**请求示例**:
```bash
curl "http://localhost:8080/api/chat?message=跑一次健康巡检"
```

---

### 1.3 同步对话

**接口**: `GET /api/chat/sync`

**描述**: 发送用户消息，同步返回完整结果（纯文本）。

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|:------|:----|:----|:------|
| message | String | 是 | 用户输入的消息内容 |
| sessionId | String | 否 | 会话 ID，不传则自动生成 |

**请求示例**:
```bash
curl "http://localhost:8080/api/chat/sync?message=查一下payment-service当前部署的版本"
```

**响应示例**:
```
[健康巡检] 开始检查系统...
[指标检查] Prometheus 未配置，使用 Mock 数据
...
```

## 3. 服务连接管理

### 3.1 获取连接列表

**接口**: `GET /api/connections`

**描述**: 获取所有已注册的服务连接，或按类型过滤。

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|:------|:----|:----|:------|
| type | String | 否 | 连接类型过滤（mysql/redis/es/prometheus/k8s/log/service）|

**请求示例**:
```bash
# 获取所有连接
curl "http://localhost:8080/api/connections"

# 按类型过滤
curl "http://localhost:8080/api/connections?type=mysql"
```

**响应示例**:
```json
[
  {
    "id": 1,
    "name": "生产环境 MySQL",
    "type": "mysql",
    "host": "192.168.1.100",
    "port": 3306,
    "username": "admin",
    "config": "{}",
    "createdAt": "2026-06-02T10:00:00"
  }
]
```

---

### 3.2 获取单个连接

**接口**: `GET /api/connections/{id}`

**描述**: 根据 ID 获取单个服务连接详情。

**路径参数**:

| 参数名 | 类型 | 必填 | 说明 |
|:------|:----|:----|:------|
| id | Long | 是 | 连接 ID |

**请求示例**:
```bash
curl "http://localhost:8080/api/connections/1"
```

**响应**: 同列表接口单条数据

**状态码**:
- `200`: 成功
- `404`: 连接不存在

---

### 3.3 创建连接

**接口**: `POST /api/connections`

**描述**: 注册新的服务连接。

**请求体**:
```json
{
  "name": "生产环境 MySQL",
  "type": "mysql",
  "host": "192.168.1.100",
  "port": 3306,
  "username": "admin",
  "password": "xxx",
  "config": "{\"database\":\"devops_copilot\"}"
}
```

**请求示例**:
```bash
curl -X POST "http://localhost:8080/api/connections" \
  -H "Content-Type: application/json" \
  -d '{"name":"测试Redis","type":"redis","host":"127.0.0.1","port":6379}'
```

**响应**: 返回创建的连接对象（含 ID）

---

### 3.4 更新连接

**描述**: 更新已有的服务连接配置。

**路径参数**:

| 参数名 | 类型 | 必填 | 说明 |
|:------|:----|:----|:------|
| id | Long | 是 | 连接 ID |

**请求体**: 同创建接口

**请求示例**:
```bash
curl -X PUT "http://localhost:8080/api/connections/1" \
  -H "Content-Type: application/json" \
  -d '{"name":"生产环境 MySQL（已更新）","type":"mysql","host":"192.168.1.100","port":3306}'
```

**响应**: 返回更新后的连接对象

**状态码**:
- `200`: 成功
- `404`: 连接不存在

## 5. 知识库管理

### 5.1 搜索知识库

**接口**: `GET /api/knowledge`

**描述**: 根据查询语句搜索知识库，返回相关文档。

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|:------|:----|:----|:------|
| q | String | 是 | 搜索关键词 |

**请求示例**:
```bash
curl "http://localhost:8080/api/knowledge?q=数据库连接池配置"
```

**响应示例**:
```json
{
  "query": "数据库连接池配置",
  "result": "根据知识库检索，数据库连接池建议配置：\n1. 初始连接数：10\n2. 最大连接数：100\n3. 超时时间：30s\n..."
}
```

---

### 5.2 添加文档

**接口**: `POST /api/knowledge`

**描述**: 向知识库添加新文档。

**请求体**:
```json
{
  "docId": "doc-001",
  "title": "MySQL 连接池配置指南",
  "content": "本文档介绍如何配置 MySQL 连接池...",
  "tags": ["mysql", "连接池", "配置"]
}
```

**请求示例**:
```bash
curl -X POST "http://localhost:8080/api/knowledge" \
  -H "Content-Type: application/json" \
  -d '{"title":"Redis 缓存策略","content":"Redis 缓存常用策略介绍...","tags":["redis","缓存"]}'
```

**响应示例**:
```json
{
  "docId": "doc-1717300000000",
  "title": "Redis 缓存策略",
  "status": "created"
}
```

**错误响应**:
```json
{
  "error": "title 和 content 不能为空"
}
```

**状态码**:
- `200`: 创建成功
- `400`: 请求参数错误
- `500`: 写入失败

## 附录

### A. 数据模型

#### ServiceConnection（服务连接）

| 字段 | 类型 | 说明 |
|:----|:----|:------|
| id | Long | 主键 |
| name | String | 连接名称 |
| type | String | 连接类型（mysql/redis/es/prometheus/k8s/log/service）|
| host | String | 主机地址 |
| port | Integer | 端口号 |
| username | String | 用户名 |
| password | String | 密码 |
| config | String | 额外配置（JSON 格式）|
| createdAt | LocalDateTime | 创建时间 |

#### ModelConfig（模型配置）

| 字段 | 类型 | 说明 |
|:----|:----|:------|
| id | Long | 主键 |
| name | String | 模型名称 |
| provider | String | 供应商（ollama/openai）|
| modelName | String | 模型名称 |
| type | String | 模型类型（chat/embedding）|
| baseUrl | String | 基础 URL |
| apiKey | String | API 密钥 |
| active | Boolean | 是否激活 |
| createdAt | LocalDateTime | 创建时间 |

#### Conversation（会话）

| 字段 | 类型 | 说明 |
|:----|:----|:------|
| id | Long | 主键 |
| sessionId | String | 会话标识 |
| title | String | 会话标题 |
| createdAt | LocalDateTime | 创建时间 |
| updatedAt | LocalDateTime | 更新时间 |
