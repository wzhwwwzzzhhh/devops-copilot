## 1. 页面结构

### 1.1 整体布局

采用 **三栏式布局**：

```
┌─────────────────────────────────────────────────────────────┐
│                      顶部导航栏 (nav)                         │
│  [Logo] [会话名称]                    [模型状态] [模型选择] [设置] [侧栏] │
├──────────┬──────────────────────────────────────┬───────────┤
│          │                                      │           │
│  左侧栏  │           主对话区                     │  右侧面板  │
│ (sidebar)│           (main)                     │(rightPanel)│
│          │                                      │           │
│ 会话列表  │  [欢迎页 / 对话消息]                   │ 系统状态   │
│ 新建按钮  │  [快捷指令栏]                         │ 服务列表   │
│ 状态栏   │  [输入框 + 发送按钮]                   │ 模型信息   │
│          │                                      │ 知识库     │
└──────────┴──────────────────────────────────────┴───────────┘
```

### 1.2 HTML 结构

| 区域 | 类名/ID | 说明 |
|:----|:--------|:------|
| 顶部导航 | `.nav` | 固定高度 56px，包含 Logo、会话名、模型选择器、设置按钮 |
| 左侧栏 | `.sidebar` (#sidebar) | 宽度 260px，可折叠，包含会话列表和状态栏 |
| 主对话区 | `.main` | 自适应宽度，包含聊天区和输入区 |
| 聊天区 | `.chat` (#chat) | 显示欢迎页或对话消息列表 |
| 输入区 | `.input-area` | 包含快捷指令栏和输入框 |
| 右侧面板 | `.right-panel` (#rightPanel) | 宽度 280px，可折叠，显示系统状态 |
| 设置弹窗 | `.modal-overlay` (#settingsModal) | 固定定位，包含三个 Tab 页 |

## 4. 接口对接

### 4.1 接口调用汇总

| 前端功能 | 调用接口 | 方法 | 说明 |
|:--------|:--------|:----|:------|
| 加载会话列表 | `/api/sessions` | GET | 页面加载时调用 |
| 发送消息（流式） | `/api/chat` | GET (EventSource) | SSE 流式对话 |
| 发送消息（同步） | `/api/chat/sync` | GET | 快捷指令使用 |
| 加载连接列表 | `/api/connections` | GET | 设置弹窗打开时调用 |
| 添加连接 | `/api/connections` | POST | 表单提交 |
| 删除连接 | `/api/connections/{id}` | DELETE | 确认后调用 |
| 加载模型列表 | `/api/models` | GET | 设置弹窗打开时调用 |
| 添加模型 | `/api/models` | POST | 表单提交 |
| 激活模型 | `/api/models/{id}/activate` | PUT | 切换模型 |
| 删除模型 | `/api/models/{id}` | DELETE | 确认后调用 |
| 获取当前模型 | `/api/models/current` | GET | 更新状态指示器 |
| 搜索知识库 | `/api/knowledge?q=xxx` | GET | 快捷指令或弹窗搜索 |
| 添加知识库文档 | `/api/knowledge` | POST | 表单提交 |
| 加载右侧面板 | `/api/connections` + `/api/models` | GET | 组合调用 |

### 4.2 SSE 事件处理

```javascript
eventSource.addEventListener('message', (e) => {
  // 接收流式消息片段，追加到聊天区
  appendBotText(e.data)
});

eventSource.addEventListener('done', (e) => {
  // 对话完成，关闭连接，更新状态
  eventSource.close();
  loadSessions();
});

eventSource.addEventListener('error', (e) => {
  // 服务端错误，展示错误信息
  addMsg('bot', '❌ 处理失败: ' + e.data);
});

eventSource.onerror = () => {
  // 连接断开，展示断开提示
  addMsg('bot', '❌ 连接断开，请重试');
};
```

## 6. 交互逻辑

### 6.1 页面加载流程

```
DOMContentLoaded
    ↓
loadSessions()     → 加载会话列表
loadConnections()  → 加载服务连接
loadModels()       → 加载模型配置
loadRightPanel()   → 加载右侧面板
updateModelStatus()→ 更新模型状态
```

### 6.2 发送消息流程

```
用户输入消息
    ↓
校验非空 + 非加载状态
    ↓
判断是否为快捷指令
    ├─ /健康巡检 → 调用同步接口 → 展示结果
    ├─ /知识库   → 调用知识库接口 → 展示结果
    └─ 普通消息  → 建立 SSE 连接 → 流式展示
```

### 6.3 SSE 流式对话流程

```
1. 关闭旧 EventSource（如有）
2. 创建新 EventSource 连接 /api/chat
3. 监听 'message' 事件 → 逐字追加文本
4. 监听 'done' 事件 → 关闭连接，更新会话列表
5. 监听 'error' 事件 → 展示错误信息
6. 监听 onerror → 处理连接断开
```

### 6.4 表单验证规则

| 表单 | 必填字段 | 验证逻辑 |
|:----|:--------|:--------|
| 服务连接 | 名称、地址 | 非空检查，空则 alert 提示 |
| 模型配置 | 名称、API 地址 | 非空检查，空则 alert 提示 |
| 知识库文档 | 标题、内容 | 非空检查，空则 alert 提示 |

## 8. 已知限制

| 限制 | 说明 | 优先级 |
|:----|:------|:------|
| 无框架依赖 | 使用原生 JS，无 Vue/React | 设计选择 |
| 无状态管理 | 无 Vuex/Redux，状态分散在函数中 | 可优化 |
| 无路由系统 | 单页面，无路由切换 | 可优化 |
| XSS 防护 | 使用 `escHtml()` 转义，但非完整方案 | 可加强 |
| 错误处理 | 部分接口调用无详细错误提示 | 可优化 |
