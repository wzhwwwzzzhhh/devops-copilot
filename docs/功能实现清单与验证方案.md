# DevOps Copilot - 功能实现清单与验证方案

> 最后更新: 2026-05-31 (v2.0)
> 架构: 图引擎 + ReAct 模式

---

## 一、核心架构

```
ToolRegistry(6 tools) → ReActNode(LLM决策) → CallToolNode(执行)
                              ↑ 条件路由 ↓
                     FINAL_ANSWER → AwaitingApproval → ExecuteAction → GenerateReport → END
                              ↘ GENERATE_REPORT → END
健康巡检/单步指令 → 独立节点直接处理
```

## 五、核心链路验证

### ReAct 链路（有 Ollama）
```
START → REACT_DECIDE(LLM决策)
  → TOOL → CALL_TOOL(执行) → REACT_DECIDE(再次决策)
  → FINAL_ANSWER → AWAITING_APPROVAL(如需审批) → EXECUTE_ACTION → GENERATE_REPORT → END
```

### 降级链路（无 Ollama）
```
START → REACT_DECIDE → 检测到LLM不可用 → fallback:
  query_metrics → query_logs → query_traces → check_db_status → list_deployments
  → FallbackAnalyzer.analyzeFromData() → GENERATE_REPORT → END
```

### 健康巡检链路
```
START → HEALTH_CHECK_START → HEALTH_CHECK_METRICS
  → HEALTH_CHECK_LOGS → HEALTH_CHECK_DATABASE
  → HEALTH_CHECK_DEPLOYMENTS → HEALTH_CHECK_ANALYZE → GENERATE_REPORT → END
```

### 单步指令链路
```
START → DIRECT_QUERY → END
```
