# DevOps Copilot - 开发计划

## 项目信息
- **项目名**: devops-copilot
- **包名**: com.devboss
- **定位**: 智能研发效能助手（AI Agent），可插拔式中间件接入
- **核心价值**: ReAct 自主决策 + 图引擎编排 + 人机协作审批 + 插件化数据源
- **交互方式**: CLI 命令行（日常排查）+ Web 管理页面（配置管理）

---

## 技术栈

| 维度 | 选择 |
|:---|:-----|
| 主语言 | Java 17 |
| 框架 | Spring Boot 3.4.4 + Spring AI 1.1.2 |
| 构建工具 | Maven |
| 持久层 | MySQL 8.0（6 张表：业务数据 / 日志 / 配置）+ Redis 7（会话缓存）|
| 知识库 | Elasticsearch 8.15（运维文档检索，REST API 直调）|
| LLM 集成 | 支持任意 OpenAI 兼容接口（Ollama / 通义千问 / DeepSeek 等），含数据驱动降级 |
| 前端 | CLI 命令行 + Web 管理页面（三栏布局：会话侧栏 / 对话区 / 系统状态面板）|
| 数据源 | 用户通过 Web 页面注册（MySQL / Redis / ES / Prometheus / K8s / 日志路径等）|

## 核心设计原则

### 1. 数据源插件化
```
用户通过 Web 页面注册 MySQL/Redis/Prometheus 地址 → 存 MySQL service_connections 表
→ 工具调用时：有注册 → 连真实系统；未注册 → 读 Mock 数据
→ 新用户开箱即用，有环境的一键对接
```

### 2. 健康巡检只查用户注册的服务
```
用户注册了哪些 type=service 的连接，就查哪些
一个都没注册 → 提示"请先注册服务"
```

### 3. ReAct 自主决策
```
LLM 自主决定调什么工具、按什么顺序
不可用时 → FallbackAnalyzer 基于真实数据自动分析（不需要 LLM）
```

### 4. Web 管配置，CLI 管排查
```
Web 页面（管理端）：注册中间件、配模型、管理知识库
CLI 命令行（日常端）：报障排查、健康巡检、快速查询
Web 无文件系统权限，CLI 可读本地日志，各司其职
```

## API 总览

| 接口 | 方法 | 说明 |
|:----|:----|:------|
| `/api/chat` | GET/POST | SSE 流式对话 |
| `/api/chat/sync` | GET | 同步对话（纯文本返回）|
| `/api/health` | GET | 健康检查 |
| `/api/sessions` | GET | 会话列表 |
| `/api/connections` | GET/POST | 服务连接 CRUD |
| `/api/connections/{id}` | GET/PUT/DELETE | 单条连接操作 |
| `/api/connections/services` | GET | 已注册服务名列表 |
| `/api/connections/types` | GET | 支持的类型列表 |
| `/api/models` | GET/POST | 模型配置 CRUD |
| `/api/models/current` | GET | 当前聊天模型 |
| `/api/models/{id}/activate` | PUT | 切换为当前模型 |
| `/api/models/providers` | GET | 支持的供应商列表 |
| `/api/knowledge` | GET/POST | 知识库搜索 / 添加文档 |
