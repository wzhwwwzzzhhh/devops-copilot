### 各区域详细说明

#### 1. 顶部导航栏（高度 60px）

- **左侧**：项目Logo + 当前会话名称（可编辑）

- **中间**：模型选择下拉（Ollama/通义千问/DeepSeek/OpenAI），显示当前可用性（绿点/红点）

- **右侧**：设置图标（配置数据源、知识库）、用户头像

#### 2. 左侧边栏（宽度 260px，可折叠）

- **新建会话** 按钮（醒目，如绿色渐变）

- **会话历史列表**：按时间倒序，每条显示简短预览（如“查order-service故障...”），支持重命名、删除

- **底部**：系统状态指示（Mock模式 / 真实连接；LLM是否可用）

#### 3. 主对话区域（核心区域，自适应宽度）

这是最像DeepSeek的部分，但需要增强**工具调用可视化**：

- **用户消息**：右对齐，浅色气泡（深色模式下用深灰底）

- **Agent消息**：左对齐，包含三个部分：
  
  - 文本推理过程（正常展示）
  
  - **工具调用卡片**（可折叠）—— 显示调用了什么工具、参数、返回结果摘要，成功/失败状态。这是你的亮点，一定要突出。
  
  - **审批按钮**：当Agent需要人工确认时，直接在消息内显示一个亮色的按钮组（同意/拒绝/查看详情）。

- **思考过程**：可以用小字号、灰色斜体展示（例如“正在查询监控数据...”），或者用Loading骨架屏。

#### 4. 右侧面板（宽度 280px，可折叠）

这个区域是运维Agent独有的，用来展示“当前会话的上下文状态”，避免用户在对话中迷失：

- **当前可用工具列表**：展示已配置的8类工具（监控、日志、数据库、部署、知识库等），绿色圆点表示连接正常。

- **知识库快照**：展示本次会话中检索到的知识文档标题，点击可展开内容。

- **待审批任务队列**：如果有多个待确认动作，列表展示，不必滚动历史消息去找。

- **执行历史**：最近5个已执行的工具调用及结果（简化版）。

#### 5. 底部输入区（高度 100-120px）

- **多行输入框**（支持Shift+Enter换行，Enter发送）

- **快捷指令按钮**：用类似ChatGPT的斜杠命令，例如：
  
  - `/健康巡检` → 自动触发一键检查
  
  - `/查版本 [服务名]` → 单步指令
  
  - `/知识库 搜索...` → 检索知识

- **附加设置**：是否开启自动执行（安全模式），是否显示详细调用链。
